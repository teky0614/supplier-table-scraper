# 表格同步规则（按表头名称定位）

## ★ 第一原则：按表头名称定位列，绝不按列字母/序号

列顺序可能因以后增删列而改变，但**表头名称不变**。任何对比、插入、删除、清洗操作前：

1. 先读两个表的**表头行**，建立 `名称 → 实际列字母` 的映射。
2. 用**名称**去找目标列，把映射传给子代理（sheet-agent），不要说"A列/B列"这种硬编码。
3. **相似/重复名称判定**：当出现近似表头（如"标题未清洗" vs "清洗后标题"；或两个都叫"链接"），看该列下面 3~5 行的**内容**判定：
   - "标题未清洗"类：内容通常含"日本正版"开头、含"扭蛋"。
   - "清洗后标题"类：内容不含"日本正版"开头，"扭蛋"通常已被删掉。
   - "链接"类：内容是 `https://item.taobao.com/...`。
   - "价格/原袋价格"类：内容是纯数字。
4. **拿不准就问用户**，不要凭猜测定位列。定位错误会导致整列数据错位。

### 本次实际表头对照（仅作参考，实际以每个文件读到的表头为准）

| 用途 | 临时表表头 | 总表表头 |
|---|---|---|
| 原始标题（匹配键、清洗源） | 商品标题 | 标题未清洗 |
| 清洗后标题 | — | 清洗后标题(B列) |
| 链接（唯一键、删除定位键） | 商品链接 | 链接 |
| 价格 | 价格（元） | 原袋价格 |
| 序号 | 序号 | — |

总表其他列（按名称）：对比公式、颜色分类、蛋壳直径、广告图、编码。
注意总表可能出现无名表头如 `Unnamed: 3`——这类列不属于任何已知名称，插入行时留空。

## 完整同步流程（用户已确认的最终版）

前提：临时表已由 Step 6 生成（表头：序号/商品标题/商品链接/价格（元））。

### 0. 备份
改总表前先复制备份：`总表_备份_YYYYMMDD.xlsx`。

### 1. 正向同步：临时表有、总表无 → 插入行
- **匹配**：临时表「商品标题」逐行对比总表「标题未清洗」，只接受**完全一致**（精确字符串相等），禁止模糊/智能/同款/改名推断。
- 把新增行插入到**表头之下**（第 2 行前），保持临时表内原始顺序。
- 列映射（按名称）：
  - 临时「商品标题」→ 总「标题未清洗」（原文不动）
  - 临时「商品链接」→ 总「链接」
  - 临时「价格（元）」→ 总「原袋价格」（纯数值，去掉 ¥ 符号）
  - 清洗后标题 → 总「清洗后标题(B列)」（见步骤 4）
  - 其他列留空。

### 2. 反向同步：总表有、临时表无 → 删除行
- 同样按标题精确对比，找出总表独有行，从总表**删除整行**。
- ⚠️ **关键坑**：两表商品集合可能一致但**行顺序不同**（曾出现总表待删行集中在第 11–41 行，临时表却分散在第 95–970 行）。必须用**商品链接做唯一键**分别定位各自行号，**从下往上**删除，绝不能按相同行号删。

### 3. 删除价格>700 / 不含"扭蛋"的行（独立步骤，也要执行）
- 条件：价格 > 700 **或** 标题不含"扭蛋"（并集）。
- 两表**都要删**同样这批商品（保持对齐）。
- ⚠️ **"不含扭蛋"必须用原始标题判断**（总表「标题未清洗」、临时表「商品标题」），**绝不能用「清洗后标题」**——那一列已被清洗掉"扭蛋"，用它判断会误删几乎所有行（曾测出 986 行里只剩 5 行含"扭蛋"）。
- 同样用链接做键、从下往上删。

### 4. 标题清洗
对（正向插入的）新行，取「标题未清洗」原文，清洗后填入「清洗后标题」列：
1. 去掉开头的"日本正版"（连同其后紧跟的空格）。
2. 找**最后一个**"扭蛋"，把它和它后面所有文字删掉，保留之前部分并去掉尾部空格。
   - 例：`日本正版TOMY 三丽鸥白菜装扮造型扭蛋 凯蒂猫美乐蒂玉桂狗` → `TOMY 三丽鸥白菜装扮造型`
- 注意：不含"扭蛋"的标题（盒蛋/景品/手办）只做第 1 步；"台湾正版"等前缀按规则保留原样（规则只要求去"日本正版"）。如需额外处理，先问用户。

### 5. 底色标记
- 旧标记：总表数据行（第 2 行起）底色非白的全部改白（FFFFFFFF 或无填充）；**表头第 1 行不动**。
- 新插入行：整行所有列（A–J，即全部表头列）改成浅粉色，色值**读取总表原有粉色单元格的 hex**（曾为 `FFC7CE` = ARGB `FFFFC7CE`），保持视觉统一。

## 校验清单（主代理必须独立回读，不轻信子代理）

- [ ] 备份文件存在
- [ ] 两表数据行数符合预期、表头名称与位置一致
- [ ] 标题/链接双向 0 独有（正向+反向+删除全部完成后）
- [ ] 共同标题价格一致
- [ ] 无残留的应删行（价格>700 或原始标题不含"扭蛋"）
- [ ] 新行清洗规则逐行复核（可脚本重算对比）
- [ ] 底色：旧标记已白、新行粉色、表头未动
- [ ] 表头行内容未被修改
- [ ] 临时截图、临时脚本已清理

## 已知异常记录（供判断参考，不是规则）

- 临时表可能出现**同标题不同价**的重复行（曾见第 804/805 行同标题、价格 1344/1368）。按精确匹配规则，若都不在总表会都插入，不去重。是否去重需问用户。
- 部分标题以"台湾正版"开头 → 默认保留。
- "不含扭蛋"的盒蛋/景品/手办类标题 → 清洗只去"日本正版"。

## 委派 sheet-agent 的要点

传给子代理：① 两个工作簿绝对路径；② 表头名称→列字母映射 + 相似名称内容判定法；③ 本文件相关规则；④ 期望返回（匹配数、插入/删除数、清洗抽查、底色 hex、校验结果）。
强调：按名称定位、链接做键从下往上删、原始标题判断扭蛋、先备份、不改表头。
子代理完成后主代理必须独立回读校验。
