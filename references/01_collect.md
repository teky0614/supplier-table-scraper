# 01 · 全店采集（至尊宝）

## 环境

| 项 | 值 |
|---|---|
| 浏览器 | Edge，CDP 端口 **9333**，独立 profile `C:/Users/Administrator/.cdp-taobao` |
| 插件 | 至尊宝 v30.3.4（扩展 ID 随安装方式变：`kcbibcclghjmmhlbeocbemccglagfdik` 手动装 / `cblppppgofckndenhnnipibfaegicoli` 命令行装） |
| 其他端口 | 9222 拼多多、9223 小红书、9334 独立 Chrome、9336 360 浏览器 —— 一律不许干扰 |

检查顺序（缺一不可）：

```bash
"$PY" "$S/human_input.py" status   --port 9333   # {"ok":true,"browser":...}
"$PY" "$S/human_input.py" url      --port 9333   # 是否店铺页
"$PY" "$S/human_input.py" title    --port 9333   # 标题含店铺名，如「首页-扭蛋供应商-淘宝网」
"$PY" "$S/human_input.py" viewport --port 9333   # innerW/innerH/dpr
curl -s http://127.0.0.1:9333/json/list | grep service-worker   # 插件是否加载
```

- 若跳到登录页 → 通知用户手动登录，登录后继续，**不要尝试自动填账号**。
- 若 CDP 不通 → 用 `browser-automation-cdp` 的 `start_chrome.py` 起浏览器；Bash 里用 `&` 挂的浏览器会随命令结束被杀，必须 `run_in_background=true` 保活（启动后 `tail -f /dev/null` 常驻）。
- Chrome 137+ 已忽略 `--load-extension`；需要插件只能用「用户手动装好插件的 profile」或 360 浏览器（Chromium 108 仍支持）。

## 截图定位（坐标系是唯一容易出错的地方）

1. 截图尺寸与 CSS 坐标通常 1:1（`dpr=1`）；若不一致，按 `截图尺寸 / 视口尺寸` 换算点击坐标。
2. **CDP `Page.captureScreenshot` 的 `clip` 是文档坐标**，页面滚动后会截到空白。要局部放大，就先把整图落成 PNG，再用 Pillow 裁剪子图（视口坐标）。
3. 窗口尺寸一变，元素位置全变 → **每次点击前重新截图**，绝不复用上一批坐标。
4. 工具栏常吸顶，滚动前后 y 不同；点「全选/复制」前必须重新截。
5. 截图用完立即删（用户硬盘不留一堆 png）。

定位辅助：视觉缩放判断不准时，按颜色扫像素（例如「复制」是蓝色实心块），或从 PNG 裁局部放大 3~5 倍再看。

## 点击与滚动（防风控）

```bash
"$PY" "$S/human_input.py" click --port 9333 <x> <y> --jitter 2
"$PY" "$S/human_input.py" wheel --port 9333 <x> <y> 1600 --steps 7 --pause 0.5 --jitter 6
```

- 每批滚动总距离 900~2100px，分 5~9 小步，每步坐标随机抖动、停留 0.35~0.6s。
- 每批后截图判断：出现新商品 → 继续；出现「没有更多商品」→ 到底；出现「加载中」且 10s+ 无新增 → 先向上回滚几屏再往下（犹豫/重复更像人）。
- 滚动中鼠标误触商品卡弹出插件浮层 → 别管，等它自然消失。
- 全程只发 `Input.dispatchMouseEvent`。遇风控/滑块/验证框 → 立即停止并通知用户。

## 全选 + 复制

1. 重新截图定位吸顶工具栏的「全选」复选框和「复制」按钮。
2. 点全选 → 截图确认变成 `全选(N/N)`、商品勾全部打勾。
3. 点复制 → 若弹《商品数据复制导出使用协议》→ 直接点「同意并继续」（用户已授权，这类弹窗不必问；其他未知弹窗要问）。
4. **点完立即截图**（提示框几秒就消失），读中间半透明提示「复制链接&标题&价格成功,数量:N」。
5. 没抓到就再点一次复制重截；连续两次失败 → 停，问用户。
6. 记下 N。它是阶段 2 护栏的分子。

## 剪贴板 → 临时表

- 读系统剪贴板（PowerShell `Get-Clipboard -Raw`）。这是系统剪贴板，不是网页元素，合规。
- 格式：制表符分隔三列 `标题\t\t链接\t\t价格`（**双 tab**，价格纯数字）。先统计行数/列数、抽查首尾行，确认格式无误。
- 落盘 xlsx，表头固定：`序号 | 商品标题 | 商品链接 | 价格（元）`，文件名用「店铺-分类-排序」，如 `扭蛋供应商-潮玩扭蛋-新品.xlsx`。
- 逐行比对源数据，0 不匹配才继续。行数必须等于 N；不等 → 大概率有换行符串行，先查再走。

## 常见坑

| 现象 | 原因 / 处理 |
|---|---|
| 复制出来行数少于 N | 标题里含换行，或被剪贴板截断；重新全选复制一次 |
| 价格带 `¥` 或千分位 | 同步脚本 `num()` 已剥离，不用手改 |
| 分类点错导致只抓到几十条 | 护栏会拦；但别依赖护栏，点完必须截图确认选中态 |
| 页面滚动后点「全选」没反应 | 工具栏吸顶位置变了，重截重定位 |
| 点复制弹未知弹窗 | 停，问用户，别猜着点 |
